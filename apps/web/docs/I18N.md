# i18n (web)

Library: `i18next` + `react-i18next` + browser language detector.

```
src/i18n/
├── index.ts          i18next setup, resources, language detection
├── types.ts          types for translation keys (from the English files)
└── locales/
    ├── en/{common,home,about}.json
    └── es/{common,home,about}.json
```

One file per namespace. Use a namespace with `useTranslation("home")`.

Default language: `DEFAULT_LANGUAGE` in `src/i18n/index.ts` (applies on first launch; the user's choice is then saved in localStorage).

For the full guide (add a namespace, add a language) see [docs/I18N.md](../../../docs/I18N.md) in the repo root. The steps are the same here.
